# Mod MiB, etap 1 na 1.21.11: plan wdrożenia

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mod MiB dla Minecraft 1.21.11 (Fabric) zawiera:
- menu pod prawym Shiftem (makieta A);
- edytor HUD;
- wspólny zapis ustawień i ochronę serwerową;
- 16 modułów etapu 1.

Launcher (wersja 0.12.0) sam instaluje mod z Fabric API i Sodium, a „Zmień konto” przechodzi ze starej nakładki do menu moda.

**Architecture:**
- **Część wspólna (`mod/common`):** czysta Java 8 bez zależności i bez klas Minecrafta. Zawiera:
  - JSON i zapis ustawień;
  - katalog modułów, wyszukiwarkę i teksty PL/EN;
  - logikę modułów;
  - układ HUD i edytor;
  - **całe menu**, rysowane przez interfejs `Canvas`;
  - ochronę serwerową i most do launchera.
- **Kopia dla 1.21.11 (`mod/fabric-1.21.11`)** to tylko adaptery:
  - `Canvas` na `DrawContext`, `GameInfo` z danych gry;
  - ekrany przekazujące wejście do widoków wspólnych;
  - rejestracja HUD i klawiszy;
  - mixiny dla Zoom, FOV, Brightness i CPS.
- **Kod wspólny jest kompilowany razem z kopią** (katalog źródeł dołączony w Gradle), więc w pliku `.jar` nie ma osobnej biblioteki.
- **Launcher:** logika bez efektów ubocznych w `lib/mibmod.js` (testy `node --test`), a podłączenie w `main.js`.

**Tech Stack:**
- **Mod:** Gradle 9.7.1 (wrapper skopiowany z `FabricMC/fabric-example-mod`, gałąź 1.21.11), Fabric Loom `net.fabricmc.fabric-loom-remap` 1.18-SNAPSHOT, mapowania Yarn, JUnit 5 (z `https://repo1.maven.org/maven2/`).
- **CI:** GitHub Actions z testem klienta Fabric (`runClientGameTest` pod `xvfb-run`).
- **Launcher:** Electron 31, testy `node --test`.

**Spec:** `docs/superpowers/specs/2026-10-16-mib-mod-design.md` (makieta: `docs/superpowers/specs/2026-10-16-mib-mod-menu-A.png`)

## Global Constraints

- **Wersje:**
  - `minecraft_version=1.21.11`, `loader_version=0.19.5`, `fabric_api_version=0.141.6+1.21.11`, `loom_version=1.18-SNAPSHOT`, `yarn_mappings=1.21.11+build.6`;
  - przy pierwszym buildzie na CI sprawdzić, że build Yarn istnieje. Jeśli nie, wziąć najnowszy `1.21.11+build.N` i poprawić tylko tę linię.
- **Java:**
  - `mod/common` kompiluje się z `options.release = 8`;
  - `mod/fabric-1.21.11` kompiluje się z `release = 21`;
  - w `common` nie wolno używać niczego spoza JDK 8: żadnych `var`, rekordów, `List.of`, `String.repeat` ani Gsona.
- **Identyfikatory:**
  - mod id `mibclient`, pakiety `pl.mibclient.mod.core` (wspólne) i `pl.mibclient.mod.fabric` (1.21.11);
  - plik w folderze `mods` gracza: `mib-client-mod.jar`;
  - plik w zasobach launchera: `mib-mod-fabric-1.21.11.jar`.
- **Ustawienia:**
  - plik `mod-config.json` w katalogu z właściwości JVM `mib.dir`;
  - gdy jej brak, w `<katalog gry>/mib`;
  - launcher podaje `-Dmib.dir=<katalog gry launchera>/mib`, gdzie `<katalog gry launchera>` to ustawienie `root` (domyślnie `<userData>/minecraft`).
- **Kolory (ARGB) jak tokeny launchera:**

  | Token | Kolor |
  |---|---|
  | void | `0xFF07020C` |
  | slab | `0xFF100618` |
  | slab2 | `0xFF190C25` |
  | edge | `0xFF24133A` |
  | edge2 | `0xFF3A2256` |
  | am | `0xFFA855F7` |

  Przyciemnienie gry pod menu: `0xA0050010`.
- **Wygląd:** pikselowe ramki (bez pikseli w rogach), tekst fontem Minecrafta, ikony pikselowe z pixelarticons (MIT, atrybucja w `fonts/LICENSES.txt` i w wygenerowanym pliku).
- **Teksty:**
  - nazwy modułów po angielsku, jak w tabeli spec;
  - napisy i opisy po polsku, gdy język gry zaczyna się od `pl_`, a w innym języku po angielsku;
  - każdy nowy napis launchera po polsku z wpisem w `EN` (`ui.js`).
- **Klawisze:** prawy Shift (`GLFW_KEY_RIGHT_SHIFT`) otwiera i zamyka menu (zamyka też Esc), Zoom domyślnie C. Oba zmienia się w Sterowaniu Minecrafta, w kategorii „MiB Client”.
- **Bez cheatów:** żadnego x-raya, ESP, autoclickera, automatycznego jump resetu, zmiany zasięgu ani odrzutu, auto-celowania. Moduł nigdy nie klika ani nie rusza postacią za gracza.
- **Brak moda nie może psuć gry ani launchera.** Na wersjach innych niż 1.21.11 wszystko działa jak w 0.11.0, łącznie ze starą nakładką.
- **Wydanie:** wersja launchera `0.12.0`. Właściciel sam klika „Publish release”.

   Test: Task 6 `MenuLayoutTest.tinyWindowUsesFewerColumns`, Task 4 `HudLayoutTest.positionIsClampedAfterResize`.

   - launcher pomija mod z jasnym komunikatem w konsoli;
   - gra startuje bez moda;
   - poprzednio skopiowany `mib-client-mod.jar` znika z `mods`.

   Test: Task 12 `planMod*`, Task 13 `prepareMibMod*`.
5. **Śmieciowe lub obce dane w plikach mostu** (`switch-request.json` z nieznanym id, aktywnym kontem, za długim id albo złym JSON-em; brak `accounts.json`):
   - launcher nic nie robi;
   - mod chowa przycisk „Zmień konto”, gdy nie ma kont.

   Test: Task 12 `readSwitch*`, Task 8 `LauncherBridgeTest.missingFileMeansNoAccounts`.
